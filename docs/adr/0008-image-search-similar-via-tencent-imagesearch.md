# 0008 - 相似图搜索采用腾讯云图像搜索相似图库，替换数据万象 CI 图库

产品需要的是"搜出内容相似的图片"（相似图搜索），而数据万象 CI 的以图搜图实测为相同图检索行为（检索结果基本只有输入图自身），能力形态不符。决定：接入独立的腾讯云图像搜索（产品 1589，API 实际为图像分析 TIIA 的图库接口：`tiia.tencentcloudapi.com`，Version 2019-05-29，CreateGroup → CreateImage → SearchImage/DeleteImages，Java SDK `tencentcloud-sdk-java-tiia`）的**通用图像图库**（GroupType=4，相同图与相似图均支持）作为图库相似检索引擎，替换并下线现有 CI ImageSearch 链路；检索返回 top 30 按相似度降序，暂不设阈值；沿用"公共图库且已过审才可被检索"的可见性规则与全量同步架构。

## Considered Options

- 数据万象 MetaInsight 智能检索：多模态能力最全，但以控制台操作为主、Java API 化程度与区域支持不明确，2026-07 刚调整计费，否决。
- 自建 CLIP 向量检索：真语义相似（跨风格"搜猫出猫"成立）、无持续云费用，但需引入模型推理栈、工程量数倍——作为二期升级路径保留；相似检索的入库/检索接口按可替换设计，未来只换特征引擎。

## Consequences

- 引入新产品开通与计费线：创建/检索图片各 10000 次/月免费额度，超量按量计费；图库 GroupType 创建后不可修改。
- 数据万象图库（100 容量）下线：停止同步，可选清理条目；CI 图库相关代码保留在 git 历史。
- 相似能力为视觉内容特征级，跨风格语义相似不保证；若上线后效果不达预期，按上述升级路径演进。
